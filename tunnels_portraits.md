# Portrait assets for the tunnels notebook

Generated with the built-in imagegen tool on 2026-09-26. Final assets are
`bennett.png`, `gantz.png`, and `winter.png` in this directory. The existing
`netanyahu.png` was used only as a style reference and was not modified.
Winter's likeness reference was a frame at 00:52 of the supplied
`vinter_bennet_comp.mp4` (the contemporary interview, not a 2014 photograph).
All four portraits serve as identifiers across both eras; historical offices
are specified by the labels beneath them.

Each asset was generated in its own call, with the common prompt followed by
the corresponding subject prompt below. Generated alpha was retained. The
scene applies a circular SVG clip when displaying the images.

Generate a DIFFERENT person as specified. Square composition, circle fills 90% of canvas, genuine transparent background outside the cream circle. No text, no flags, no extra people, no watermark. Keep expression neutral and composed, not sinister or heroic.
